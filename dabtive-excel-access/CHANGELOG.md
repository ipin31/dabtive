# Changelog

## v0.5.1

- Mengubah product landing page desktop menjadi full-width tanpa boxed outer card.
- Mengganti generator export leads XLSX dengan OpenPyXL untuk kompatibilitas Microsoft Excel.
- Menambahkan validasi workbook sebelum file export dikirim.

- Menambahkan regression test untuk export XLSX dan layout storefront.
